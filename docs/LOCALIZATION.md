# 中英文支持计划

**中文** | [English](LOCALIZATION.en.md)

当前已准备中英文文档及切换链接；以下游戏界面功能仍待实现。

## 语言与入口

- 支持简体中文 `zh-CN` 和英文 `en`。
- 首次启动时，中文系统语言使用简体中文，其余系统语言使用英文。
- 设置页提供“语言 / Language”选项，选择项使用“简体中文”和“English”本名，便于识别。
- 玩家主动选择优先于系统语言，并保存在当前设备；后续启动恢复该选择。
- 切换立即生效，不需要重新开始游戏。

## 翻译范围

菜单、按钮、操作说明、设置、城市、对手、关卡、球技、球拍、护照、比赛结果、奖励、广告入口和错误提示都使用稳定的文案键。包含动态数字的文案通过参数插入，不能把已经翻译的片段硬拼成句子。

城市名称使用标准英文写法，例如上海 / Shanghai、北京 / Beijing、成都 / Chengdu、香港 / Hong Kong。角色及球技译名要与英文玩法文档保持一致。

缺少所选语言的翻译时回退到英文，并在开发日志中报告缺项。运行界面不显示内部文案键。美术素材尽量不嵌入文字；确实需要文字的素材采用独立语言版本。

## 状态与布局

语言切换只改变显示文案，不改变比分、发球方、球轨迹、计时、关卡、球技、金币或奖励领取状态。Canvas 内绘制的文字需要在切换后更新。

两种语言分别检查按钮宽度、自动换行、字体、长名称和数字格式。翻译不得遮住球场或缩小关键触控区域。货币名称和显示语言不用于改变奖励数量或进行货币兑换。

## 验证

- [ ] 中文及英文系统语言下的首次默认值正确。
- [ ] 从中文切到英文、再切回中文后，所有可见文本同步变化。
- [ ] 重启后保留玩家选择，系统语言变化不覆盖已有选择。
- [ ] 比赛中切换语言后，比赛状态和奖励记录保持一致。
- [ ] 长对手名称、教程、奖励及广告按钮在两种语言下都能完整显示。
- [ ] 两个文案表键集合一致，参数占位符一致，缺失项回退行为可验证。

## 仓库文档

中文文档使用普通文件名，英文版使用 `.en.md` 后缀。文档顶部提供对应语言的链接；切换跳转到同一篇文档的另一语言版本。更新设计时同步更新两种语言。
