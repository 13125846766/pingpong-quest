# 声音

[English](AUDIO.en.md)

拍面击球与桌面弹跳采用乒乓球实录。素材来自 Freesound 的 michorvath 与 el_boss，两份录音均为 CC0；来源、裁剪时间和文件校验值见 [音频清单](../assets/audio/manifest.json)，许可见 [说明](../assets/audio/LICENSE.md)。运行文件随项目分发，不在比赛中访问素材网站。

落台保留三次不同的弹跳，轮换使用。击球时记录球速、左右位置与球台深度，决定音量、少量音高变化和声像：近处扣球响些，远处轻接收敛些。落台与触网在实际碰撞时播放，练习命中目标不再额外发出拍声。

背景乐为原创16小节器乐段落，78 BPM，约49秒。电钢琴、拨弦与低音由 `src/audio/music.ts` 生成，尾音跨循环边界衔接。首页打开时准备一次；触摸与点按钮不会重启。回合开始后背景音量降低，暂停和回合结束后恢复。音乐与音效仍可分别关闭。

浏览器首次交互后才开启音频。离开窗口或切到后台会暂停全部声音，返回后尝试延续播放；如果浏览器要求用户手势，下一次点击即可恢复。录音缺失时有短音兜底，浏览器不支持音频时游戏仍可运行。离线HTML内嵌四个WAV，无需网络。

`tests/audio.test.ts` 检查播放生命周期与混音；`tests/sound-events.test.ts` 检查真实碰撞事件；`tests/music.test.ts` 检查信号与循环接缝。浏览器脚本观察实际 Web Audio 播放和解码，不替代耳机与手机扬声器试听。音量和音色的实机听感仍需要人工确认。
