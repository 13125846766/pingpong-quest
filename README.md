# 乒乓闯关王 · Ping Pong Quest

**中文** | [English](README.en.md)

一个计划使用 TypeScript 和 Canvas 2D 开发的竖屏单人乒乓球游戏。玩家挑战不同城市的民间高手，用落点和变招创造扣杀机会，赢下比赛后学到对手的招牌球技。

> **项目状态：设计阶段。** 当前仓库包含玩法提案和开发路线，尚未实现游戏，也没有可运行的演示、构建产物或安装包。18 城市、108 关均为规划内容。

## 玩法方向

- 单指滑动控制球拍，停拍回球、前挥加力、斜挥变线；鼠标版直接跟随指针。
- 通过左右和长短球调动对手，逼出失衡、高球和进攻空档。
- 城市高手拥有可以观察和破解的招式，击败高手后解锁球技。
- 每座城市提供两次球技三选一，强化现有击球动作，形成不同打法。
- 完整主线规划为 18 座城市、每站 6 关；先验证 3 城市、18 关的首发范围。
- 护照收集城市印章、奖杯和球拍外观；训练场免费试用球拍。
- 游戏计划支持简体中文和 English，首次跟随系统语言，设置中可切换并保存偏好。

详细内容见 [玩法设计](docs/GAME_DESIGN.md)，实施顺序见 [开发路线](ROADMAP.md)，语言切换要求见 [中英文支持](docs/LOCALIZATION.md)。各文档顶部均提供中文 / English 切换链接。

## 计划技术方案

比赛计算、输入映射、场景绘制、奖励结算和存档分别组织。浏览器版与抖音小游戏版计划共用比赛逻辑，通过平台适配层处理输入、存储、音频和广告能力。

比赛状态独立于绘制对象，广告、退出和结算恢复需要有明确的状态转换。首版优先实现浏览器可玩原型，再验证小游戏平台适配。
